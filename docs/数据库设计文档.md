# 数据库设计文档

## 1. 数据库信息

| 属性 | 值 |
|------|-----|
| 数据库名 | OfficeItemsDB |
| 字符集 | utf8mb4 |
| 排序规则 | utf8mb4_unicode_ci |
| 存储引擎 | InnoDB |
| DBMS | MySQL 8.4.8 LTS |

## 2. ER 图（关系描述）

```
┌─────────────┐       ┌─────────────┐       ┌─────────────┐
│  Categories  │       │    Items     │       │   Origins    │
├─────────────┤       ├─────────────┤       ├─────────────┤
│ Id     (PK) │──1:N──│ Category(FK) │       │ Id     (PK) │
│ Name        │       │ ItemCode(PK) │       │ Name        │
└─────────────┘       │ ItemName     │       └─────────────┘
                      │ Origin       │──────────────┘
                      │ Specification│       (下拉取值)
                      │ Model        │
                      │ ImagePath    │
                      │ Quantity     │
                      └──────┬──────┘
                        1:N──┼──1:N
              ┌──────────────┴──────────────┐
              ▼                              ▼
      ┌─────────────┐              ┌─────────────┐
      │   StockIn    │              │   StockOut   │
      ├─────────────┤              ├─────────────┤
      │ StockInNo PK │              │ StockOutNo PK│

      │ PurchaseDate │              │ Quantity     │

```

## 3. 表结构详细设计

### 3.1 Categories（物品类别字典）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| Id | INT | PK, AUTO_INCREMENT | 类别 ID |
| Name | VARCHAR(50) | NOT NULL, UNIQUE | 类别名称 |

预置数据：纸张(1), 文具(2), 刀具(3), 单据(4), 礼品(5), 其它(6)

### 3.2 Origins（产地字典）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| Id | INT | PK, AUTO_INCREMENT | 产地 ID |
| Name | VARCHAR(100) | NOT NULL, UNIQUE | 产地名称 |

预置 13 个产地：北京、上海、广州、深圳、杭州、成都、武汉、南京、苏州、德国、日本、美国、中国台湾

### 3.3 Items（物品信息表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| ItemCode | VARCHAR(20) | PK | 物品编码 |
| ItemName | VARCHAR(100) | NOT NULL | 物品名称 |
| Category | INT | FK→Categories(Id) | 物品类别 |
| Origin | VARCHAR(100) | DEFAULT '' | 产地 |
| Specification | VARCHAR(100) | DEFAULT '' | 规格 |
| Model | VARCHAR(100) | DEFAULT '' | 型号 |
| ImagePath | VARCHAR(500) | DEFAULT '' | 图片文件路径 |
| Quantity | INT | DEFAULT 0, CHECK(≥0) | 库存数量 |

索引：`IX_Items_Category`, `IX_Items_ItemName`

### 3.4 StockIn（入库记录表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| StockInNo | VARCHAR(20) | PK | 流水号 SI+日期+序号 |
| ItemCode | VARCHAR(20) | FK→Items | 物品编码 |
| PurchaseDate | DATETIME | NOT NULL | 购买日期 |
| Quantity | INT | CHECK(>0) | 入库数量 |
| UnitPrice | DECIMAL(18,2) | CHECK(≥0) | 单价 |
| TotalPrice | DECIMAL(18,2) | CHECK(≥0) | 总价=数量×单价 |

索引：`IX_StockIn_ItemCode`, `IX_StockIn_PurchaseDate`

### 3.5 StockOut（领用/出库记录表）

| 字段 | 类型 | 约束 | 说明 |
|------|------|------|------|
| StockOutNo | VARCHAR(20) | PK | 流水号 SO+日期+序号 |
| ItemCode | VARCHAR(20) | FK→Items | 物品编码 |
| Quantity | INT | CHECK(>0) | 领用数量 |
| ApplicantId | VARCHAR(50) | NOT NULL | 领用人 ID |
| ApplyDate | DATETIME | NOT NULL | 申请日期 |
| Status | INT | CHECK(0,1,2), DEFAULT 0 | 0=申请 1=确认 2=驳回 |
| ApproveDate | DATETIME | NULL | 审批日期 |
| Remark | VARCHAR(500) | NULL | 审批备注 |

索引：`IX_StockOut_ItemCode`, `IX_StockOut_ApplicantId`, `IX_StockOut_Status`

## 4. 完整性约束命名

所有约束使用前缀命名规则：

| 前缀 | 含义 | 示例 |
|------|------|------|
| PK_ | 主键 | PK_Items |
| FK_ | 外键 | FK_StockIn_ItemCode |
| CK_ | CHECK 约束 | CK_Items_Quantity |
| UQ_ | UNIQUE 约束 | UQ_Categories_Name |
| IX_ | 索引 | IX_StockIn_ItemCode |

## 5. 触发器

| 触发器 | 触发时机 | 功能 |
|--------|----------|------|
| trg_StockIn_AfterInsert | StockIn INSERT 后 | 自动累加 Items.Quantity |
| trg_StockIn_AfterDelete | StockIn DELETE 后 | 自动回退 Items.Quantity |
| trg_StockOut_AfterUpdate | StockOut UPDATE 后 | 确认领用时自动扣减库存 |
| trg_StockOut_AfterDelete | StockOut DELETE 后 | 删除已确认记录时恢复库存 |

## 6. 存储过程

| 存储过程 | 功能 |
|----------|------|
| sp_GenerateStockInNo | 生成入库流水号 |
| sp_GenerateStockOutNo | 生成领用流水号 |
| sp_StockIn | 入库事务（写记录+更新库存） |
| sp_ApproveStockOut | 确认领用（事务） |
| sp_RejectStockOut | 驳回领用 |
| sp_StockStatistics | 按类别统计库存 |
| sp_StockInDetail | 入库明细分页查询 |
| sp_StockOutDetail | 领用明细分页查询 |
| sp_FixNegativeStock | 游标批量修正负库存 |
| sp_TopCategoryByStockIn | 按入库金额排行 |

## 7. 视图

| 视图 | 功能 |
|------|------|
| v_StockSummary | 库存汇总（含库存等级） |
| v_StockInMonthly | 入库按月汇总 |
| v_StockOutSummary | 领用按物品汇总 |
| v_ItemFullInfo | 物品完整信息（含入库总额/领用次数） |

```json
  }
]
```
