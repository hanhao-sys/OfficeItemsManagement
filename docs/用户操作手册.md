# 用户操作手册

## 一、系统概述

办公物品管理系统分为两个入口：

| 角色 | 入口 | 平台 | 功能 |
|------|------|------|------|
| 管理员 | WPF 桌面应用 | Windows | 用户维护、物品管理、入库、审批、查询 |
| 普通用户 | Web 浏览器 | 跨平台 | 库存查看、领用申请 |

---

## 二、管理员操作指南

### 2.1 登录

1. 启动桌面应用，进入登录界面
2. 输入用户名：`admin`
3. 输入密码：`0000`
4. 点击"登录"

> 用户名或密码为空时会显示红色提示。错误时显示"用户名或密码错误"。

### 2.2 主界面导航

登录后顶部有 5 个功能按钮 + 退出：

| 按钮 | 功能 |
|------|------|
| 用户维护 | 管理普通用户账号 |
| 物品信息 | 管理物品基本资料 |
| 物品入库 | 录入采购入库 |
| 物品出库 | 审批领用申请 |
| 库存查询 | 查看库存和明细 |
| 退出 | 返回登录界面 |

底部状态栏显示当前时间和操作状态。

### 2.3 用户维护

**新增用户：**
1. 点击"新增用户"
2. 输入用户 ID、密码、姓名（必填）
3. 选择性别
4. 选择出生日期
5. 输入联系电话
6. 点击"保存修改"

**修改用户：**
1. 左侧列表点击选择用户
2. 修改表单内容
3. 点击"保存修改"

**删除用户：**
1. 左侧列表点击选择用户
2. 点击"删除用户"
3. 确认弹窗点"是"

### 2.4 物品信息维护

**新增物品：**
1. 点击"新增物品"
2. 输入物品编码、名称
3. 选择物品类别（纸张/文具/刀具/单据/礼品/其它）
4. 下拉选择产地
5. 输入规格、型号
6. 可选：点击"选择图片"上传物品照片
7. 点击"保存修改"

**搜索物品：**
- 在搜索框输入编码或名称的关键词
- 点击"搜索"

### 2.5 物品入库

1. 点击物品编码旁的 `...` 按钮
2. 在弹出的物品列表中选择目标物品 → 点"确定"
3. 选择购买日期
4. 输入购买数量（> 0）
5. 输入单价
6. 总价自动计算
7. 点击"提交入库"
8. 弹出流水号确认

> 入库成功后物品库存自动累加。

### 2.6 物品出库（领用审批）

页面显示所有领用申请记录，可按状态筛选：

| 筛选项 | 说明 |
|--------|------|
| 全部 | 显示所有记录 |
| 待审批 | 仅显示状态为"申请"的记录 |
| 已确认 | 仅显示已通过的记录 |
| 已驳回 | 仅显示已拒绝的记录 |

状态颜色：🟠 申请（橙色） 🟢 确认（绿色） 🔴 驳回（红色）

**确认领用：**
1. 选中一条"申请"状态的记录
2. 点击"确认领用"
3. 确认弹窗点"是"
4. 库存自动扣减

**驳回申请：**
1. 选中一条"申请"状态的记录
2. 点击"驳回申请"
3. 确认弹窗点"是"

### 2.7 库存查询

三个 Tab 页签：

**Tab 1 — 库存总览：**
- 显示所有物品的编码/名称/类别/产地/规格/型号/库存数量
- 可按类别下拉筛选
- 零库存物品标红显示

**Tab 2 — 入库明细：**
- 按日期倒序显示所有入库记录
- 可按物品编码筛选
- 支持上一页/下一页翻页（每页 20 条）

**Tab 3 — 领用明细：**
- 显示所有领用记录
- 可按物品编码筛选
- 支持分页

## 三、普通用户操作指南

### 3.1 登录

1. 浏览器打开 `http://localhost:5000`
2. 输入用户名（如 `user01`）
3. 输入密码（如 `1234`）
4. 点击"登录"

> 默认账号：user01/1234（张三）、user02/1234（李四）

### 3.2 库存查询

登录后默认进入库存查询页面，以表格形式展示所有物品的信息和库存数量。零库存物品标红。

### 3.3 领用申请

**选择物品（两种方式）：**

方式一：下拉框直接选择
- 展开"选择物品"下拉框
- 选择目标物品
- 物品名称和当前库存自动显示

方式二：弹出窗口选择
- 点击"📋 弹出选择"按钮
- 在弹窗中可搜索物品编码或名称
- 点击对应行的"选择"按钮

**提交申请：**
1. 选择物品后，输入领用数量
2. 领用人和日期自动填入（不可修改）
3. 点击"提交申请"
4. 提交前系统会校验库存是否充足

**我的领用记录：**
页面下方表格展示当前用户的所有领用记录和审批状态：
- 🟡 申请（等待审批）
- 🟢 确认（已通过）
- 🔴 驳回（已拒绝）
