# 部署与运行指南

## 环境要求

| 软件 | 版本 | 说明 |
|------|------|------|
| .NET SDK | 8.0+ | [下载](https://dotnet.microsoft.com/download) |
| MySQL | 8.4.8 LTS | [下载](https://dev.mysql.com/downloads/) |
| Windows | 10/11 | WPF 桌面端必须 |
| 浏览器 | Chrome/Edge/Firefox | Web 端访问 |

## 一、数据库部署

### 1.1 确保 MySQL 服务运行

```bash
# Windows 检查
net start | findstr MySQL

# 如果未启动
net start MySQL84
```

### 1.2 执行 SQL 脚本

使用 Navicat 或命令行，按顺序执行：

```
Database/
├── 01_CreateDatabase.sql    # 建库（可跳过，手动建库也行）
├── 02_CreateTables.sql      # 建表 + 索引（必须）
├── 03_StoredProcedures.sql  # 存储过程（必须）
├── 04_Triggers.sql          # 触发器（建议）
├── 05_SeedData.sql          # 种子数据（必须）
└── 07_ViewsAndGrants.sql    # 视图 + 授权（建议）
```

Navicat 方式：
1. 新建数据库 `OfficeItemsDB`，字符集 `utf8mb4`
2. 双击打开数据库
3. 查询 → 新建查询 → 粘贴脚本内容 → 运行
4. 依次执行以上 6 个脚本

### 1.3 修改连接密码

两个文件需要改：

- `OfficeItemsManagement.Admin/Services/ServiceLocator.cs` 第 21 行
- `OfficeItemsManagement.Web/appsettings.json`

把 `Password=031020` 改为你的 MySQL root 密码。

## 二、编译运行

### 2.1 命令行方式

```bash
# 还原 NuGet 包
cd OfficeItemsManagement
dotnet restore

# 运行 Web 端（终端 1）
cd OfficeItemsManagement.Web
dotnet run
# → 浏览器打开 http://localhost:5000

# 运行管理端（终端 2）
cd OfficeItemsManagement.Admin
dotnet run
```

### 2.2 Visual Studio 方式

1. 打开 `OfficeItemsManagement.sln`
2. 右键解决方案 → 配置启动项目 → 多项目启动
3. Admin 和 Web 都设为"启动"
4. F5 运行

### 2.3 发布部署

```bash
# 发布 Web 端
cd OfficeItemsManagement.Web
dotnet publish -c Release -o ../publish/web

# 发布管理端
cd OfficeItemsManagement.Admin
dotnet publish -c Release -o ../publish/admin
```

## 四、常见问题

### Q: 连接数据库失败 "Unknown database"
→ 数据库未创建，执行 01_CreateDatabase.sql

### Q: 表不存在
→ 未执行建表脚本，执行 02_CreateTables.sql

### Q: 登录后库存查询报错
→ 没有种子数据，执行 05_SeedData.sql

### Q: Web 端 500 错误
→ 检查 appsettings.json 中连接字符串密码是否正确

### Q: WPF 端闪退
→ 检查 ServiceLocator.cs 中连接字符串 <br>
→ 查看事件查看器中的 .NET 运行时错误
