# 实验报告

## 现代软件实验 + 实验六：办公物品管理系统

---

## 一、实验概述

### 1.1 实验目的

1. 掌握 C# 技术的应用
2. 掌握桌面应用程序开发（WPF）
3. 掌握 Web 应用程序开发（ASP.NET Core Razor Pages）
4. 掌握 ADO.NET / EF Core 的使用
5. 设计和实现小型管理信息系统，集成高级数据库功能

### 1.2 实验内容

实现办公物品管理系统，支持管理员（WPF 桌面端）和普通用户（Web 端）两种角色。

## 四、实验六加分项实现

### 4.1 🏆 100万条记录性能测试

- 脚本 `06_SeedMillionRows.sql`：存储过程批量插入 100 万条入库记录
- 脚本 `08_PerformanceTest.sql`：包含 5 组性能测试查询 + EXPLAIN 执行计划分析
- 索引优化建议：复合索引、覆盖索引

### 4.2 🏆 高级数据库功能

| 功能 | 数量 | 说明 |
|------|------|------|
| 存储过程 | 10 个 | 流水号生成、事务入库、审批、分页、游标 |
| 触发器 | 4 个 | 入库自动更新库存、确认自动扣减、删除回退 |
| 游标 | 1 个 | sp_FixNegativeStock 批量修正负库存 |
| 完整性命名子句 | 全部 | PK_/FK_/CK_/UQ_ 前缀命名 |

### 4.3 🏆 数据库界面功能

- 库存总览：DataGrid + 类别筛选 + 零库存红色标记
- 入库明细：编码筛选 + 分页导航
- 领用明细：编码筛选 + 分页导航 + 状态颜色标记
- 领用审批：状态筛选 RadioButton + 确认/驳回按钮 + 二次确认

### 4.4 🏆 扩展 SQL 功能

- 视图：v_StockSummary（库存等级）、v_StockInMonthly（月度统计）
- 授权：GRANT SELECT/INSERT/UPDATE/DELETE + CREATE USER
- 聚合：COUNT、SUM、GROUP BY、CASE WHEN

## 七、实验总结

通过本次综合实验，完整实践了：

1. **C# 面向对象编程**：类继承、接口实现、泛型、LINQ
2. **WPF 桌面开发**：XAML 布局、数据绑定、事件处理、页面导航
3. **ASP.NET Core Web 开发**：Razor Pages、依赖注入、Session 管理
4. **EF Core 数据访问**：DbContext 配置、LINQ 查询、事务管理、分页
5. **MySQL 数据库**：表设计、约束命名、存储过程、触发器、视图、游标、授权
6. **软件工程**：分层架构、仓储模式、DTO 转换、异常处理
