---

#### 表 1：Categories（物品类别字典）

---

#### 表 2：Origins（产地字典）

| 字段名 | 数据类型 | 允许空 | 默认值 | 主键 | 外键 | 说明 |
|--------|----------|--------|--------|------|------|------|
| Id | INT | 否 | AUTO_INCREMENT | ✅ PK_Origins | — | 产地 ID，自增 |

#### 表 3：Items（物品信息表）

| 字段名 | 数据类型 | 允许空 | 默认值 | 主键 | 外键 | 说明 |
|--------|----------|--------|--------|------|------|------|
| ItemCode | VARCHAR(20) | 否 | — | ✅ PK_Items | — | 物品编码，唯一标识 |
| ItemName | VARCHAR(100) | 否 | — | — | — | 物品名称 |

#### 表 4：StockIn（入库记录表）

| 字段名 | 数据类型 | 允许空 | 默认值 | 主键 | 外键 | 说明 |

| ItemCode | VARCHAR(20) | 否 | — | — | FK_StockIn_ItemCode → Items(ItemCode) | 物品编码，ON DELETE RESTRICT |

| TotalPrice | DECIMAL(18,2) | 否 | — | — | CK_StockIn_TotalPrice | 总价 = Quantity × UnitPrice |

索引：

| 索引名 | 字段 | 类型 | 说明 |
|--------|------|------|------|
| IX_StockIn_ItemCode | ItemCode | 普通索引 | 加速按物品查入库 |
| IX_StockIn_PurchaseDate | PurchaseDate | 普通索引 | 加速按日期范围查询 |

### 2.2 实体间关系

| 父表 | 子表 | 关系 | 外键 | 删除规则 | 说明 |
|------|------|------|------|----------|------|
| Categories | Items | 1:N | Category → Id | RESTRICT | 一个类别下有多个物品 |
| Items | StockIn | 1:N | ItemCode → ItemCode | RESTRICT | 一个物品有多条入库记录 |
| Items | StockOut | 1:N | ItemCode → ItemCode | RESTRICT | 一个物品有多条领用记录 |

### 2.3 数据流

```
                    ┌─────────────────────┐
                    │   Categories (6条)   │──┐
                    │   Origins    (13条)  │  │ 字典数据（预置，基本不变）
                    └─────────────────────┘  │
                                             │ 外键引用
                    ┌─────────────────────┐  │
                    │   Items (10条)       │◄─┘
                    │   物品编码 / 名称     │
                    │   库存数量 Quantity   │
                    └────────┬────────────┘
                             │
              ┌──────────────┴──────────────┐
              ▼                              ▼
  ┌──────────────────────┐    ┌──────────────────────┐
  │   StockIn (入库)      │    │   StockOut (领用)     │
  │                      │    │                      │
  │ 新增 → Quantity 累加  │    │ 提交 → Status=0      │
  │ 删除 → Quantity 回退  │    │ 确认 → Status=1, Qty扣│
  │                      │    │ 驳回 → Status=2       │
  └──────────────────────┘    └──────────────────────┘
```

### 2.4 状态码定义

**StockOut.Status 状态码：**

| 值 | 含义 | 触发者 | 库存影响 | 颜色 |
|:--:|------|--------|----------|:----:|
| 0 | 申请 | 普通用户 | 不变 | 🟠 |
| 1 | 确认 | 管理员 | **扣减** | 🟢 |
| 2 | 驳回 | 管理员 | 不变 | 🔴 |

**状态流转图：**

```
       普通用户提交
            │
            ▼
       ┌───────┐
       │ 0 申请 │
       └───┬───┘
           │
    ┌──────┴──────┐
    ▼             ▼
┌───────┐    ┌───────┐
│ 1 确认 │    │ 2 驳回 │
└───────┘    └───────┘
 扣库存        不扣
```

### 2.6 流水号编码规则

| 表 | 格式 | 示例 | 说明 |
|------|------|------|------|
| StockIn | `SI` + yyyyMMdd + 3位序号 | SI20250115001 | 2025年1月15日 第1笔入库 |
| StockOut | `SO` + yyyyMMdd + 3位序号 | SO20250115002 | 2025年1月15日 第2笔领用 |

生成逻辑：

```sql
-- 当天序号 = 当天已有记录数 + 1
SELECT COUNT(*) + 1 FROM StockIn WHERE StockInNo LIKE 'SI20250115%';
-- → 结果: 5 → 流水号: SI20250115005
```

### 2.7 视图结构

| 视图名 | 数据源 | 字段 | 用途 |
|--------|--------|------|------|
| v_StockSummary | Items JOIN Categories | ItemCode, ItemName, CategoryName, Origin, Spec, Model, Quantity, StockLevel | 库存总览（含库存等级） |
| v_StockInMonthly | StockIn GROUP BY | Month, RecordCount, TotalQuantity, TotalAmount | 入库按月统计 |
| v_StockOutSummary | StockOut JOIN Items JOIN Categories | ItemCode, ItemName, CategoryName, ApplyCount, PendingCount, ApprovedQty, RejectedCount | 领用按物品统计 |
| v_ItemFullInfo | Items + 子查询 | ItemCode, ItemName, CategoryName, Origin, Spec, Model, Quantity, TotalInAmount, TotalOutCount | 物品完整信息 |

### 2.8 触发器清单

| 触发器 | 表 | 时机 | 操作 |
|--------|-----|------|------|
| trg_StockIn_AfterInsert | StockIn | AFTER INSERT | UPDATE Items SET Quantity += NEW.Quantity |
| trg_StockIn_AfterDelete | StockIn | AFTER DELETE | UPDATE Items SET Quantity = GREATEST(0, Quantity - OLD.Quantity) |
| trg_StockOut_AfterUpdate | StockOut | AFTER UPDATE | IF Status 0→1 THEN UPDATE Items SET Quantity -= NEW.Quantity |
| trg_StockOut_AfterDelete | StockOut | AFTER DELETE | IF Status=1 THEN UPDATE Items SET Quantity += OLD.Quantity |

### 2.9 存储过程清单

| 存储过程 | 参数 | 返回 | 功能 |
|----------|------|------|------|
| sp_GenerateStockInNo | OUT outNo | VARCHAR(20) | 生成入库流水号 |
| sp_GenerateStockOutNo | OUT outNo | VARCHAR(20) | 生成领用流水号 |
| sp_StockIn | IN ItemCode, PurchaseDate, Quantity, UnitPrice | 流水号 | 事务：写入库 + 更新库存 |
| sp_ApproveStockOut | IN StockOutNo, Approver, Remark | — | 事务：确认 + 扣库存 |
| sp_RejectStockOut | IN StockOutNo, Remark | — | 驳回领用 |
| sp_StockStatistics | — | 结果集 | 按类别统计库存 |
| sp_StockInDetail | IN ItemCode, PageNo, PageSize | 结果集 | 入库明细分页 |
| sp_StockOutDetail | IN ItemCode, PageNo, PageSize | 结果集 | 领用明细分页 |
| sp_FixNegativeStock | — | — | 游标批量修正负库存 |
| sp_TopCategoryByStockIn | IN TopN | 结果集 | 入库金额排行 |

## 三、用户数据结构（JSON 文件）

存储文件：`Users.json`

```json
[
  {
    "UserId": "user01",
    "Password": "1234",
    "Name": "张三",
    "Gender": "男",
    "BirthDate": "1990-05-15T00:00:00",
    "Phone": "13800138001"
  }
]
```

| 字段 | 类型 | 说明 |
|------|------|------|
| UserId | string | 用户 ID（登录账号） |
| Password | string | 登录密码 |
| Name | string | 真实姓名 |
| Gender | string | 性别："男" / "女" |
| BirthDate | DateTime | 出生日期 |
| Phone | string | 联系电话 |
